核心网络与接口配置

管理工作模式 (网关/桥接)、局域网 LAN & DHCP 地址池、WAN 上行接入及端口转发

工作模式选择 网关路由模式 (NAT)

选择路由器的核心网络拓扑角色。切换工作模式将自动调整 WAN/LAN 接口绑定与网络地址转换行为。

网关路由模式 (Gateway / NAT)

标准家庭与企业路由架构。路由器独立作为局域网网关，WAN 接口直连上级光猫或宽带，开启 DHCP 地址分配与硬件 NAT 加速。

AP 桥接模式 (Bridge / AP)

有线 AP 扩展模式。WAN 网口直接桥接至内网局域网 (br0)，旁路 NAT 转换，终端直接由上级主路由统一分配 IP 地址。

局域网与 DHCP 服务 (LAN)

配置路由器内网网关 IP 地址、子网掩码以及内置 DHCP 服务器的地址池分配范围与租约。

WAN 互联网接入设置 检测中...

设置上行广域网 (WAN) 接口的联网模式。支持自动获取 IP (DHCP)、固定静态 IP 以及 PPPoE 宽带拨号。

端口转发与虚拟服务器 (Port Forwarding)

将外部 WAN 端口请求映射转发到内网特定设备的指定服务端口（支持 Web 服务、NAS、游戏联机等）。

服务名称 协议 外部端口 内部 IP 内部端口 状态 操作

DMZ 隔离区主机

将所有未被端口转发占用的外部请求无条件映射给指定内部主机。

UPnP 自动端口映射

允许局域网应用（如 P2P 下载、视频会议、游戏主机）自动申请端口映射并穿透 NAT。
